# CloneMaster — المرحلة الثانية

مشروع Android بلغة Kotlin وJetpack Compose، مضبوط على Java/Kotlin JVM 17 لتفادي خطأ اختلاف أهداف JVM.

## الميزات الموجودة في هذه المرحلة
- عرض التطبيقات القابلة للتشغيل والبحث فيها.
- اختيار تطبيق وكتابة اسم مقترح واختيار أيقونة رمزية مقترحة.
- حفظ إعدادات النسخة محليًا وإمكانية حذف هذه الإعدادات.
- استخراج ملف APK الأساسي لتطبيق مثبت إلى مساحة التطبيق الخاصة.
- تصدير ملف APK المستخرج إلى مكان يختاره المستخدم، وحذف الملفات المستخرجة.

## ما لم يتم تنفيذه بعد — مهم
هذه المرحلة **لا تنشئ نسخة تطبيق مستقلة**. تغيير الاسم والأيقونة ما زال بيانات إعدادات فقط. لا يوجد حتى الآن تعديل فعلي لـ AndroidManifest/resources/package ID، ولا إعادة بناء وتوقيع للحزمة المعدلة، ولا تثبيت نسخة ثانية. استخراج APK الأساسي وحده قد لا يكفي للتطبيقات التي تستخدم split APKs.

## البناء
افتح مجلد المشروع في Kleancode ثم نفّذ Build. هذا التعديل لم يُختبر بالبناء داخل Kleancode؛ إذا ظهر خطأ، أرسل سجل البناء كاملًا.
